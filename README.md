# NguyenDevs - Armillary Sphere Wallpaper

A minimal 3D wallpaper for Wallpaper Engine, built with Three.js.

## Key Features
- **3D Armillary Sphere:** Smooth 3D core effect with custom shaders.
- **Music Visualizer:** Responsive audio visualization with multiple styles (Tectonic, Wave, Ripple).
- **Life Clock:** Real-time countdown timer based on your birth date.
- **Highly Customizable:** Adjust brightness, speed, camera distance, and particle effects directly within Wallpaper Engine settings.

## How to Use
1. Clone this repository.
2. Move the project folder into your Wallpaper Engine directory (usually `wallpaper_engine/projects/myprojects`).
3. Open Wallpaper Engine and the wallpaper will appear in your library.
