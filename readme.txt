HOW TO USE WITH WALLPAPER ENGINE:

1. Open Wallpaper Engine.
2. Click on "Wallpaper Editor" (at the bottom or top depending on version).
3. Select "Create New Wallpaper".
4. Drag and drop the "index.html" file from this folder into the editor.
5. Wallpaper Engine will automatically detect the project.
6. You can now use it as your wallpaper!

Note: All music and settings buttons have been removed as requested to keep it clean.
Background: Three.js core with End Sky shader.
Title and Timer are kept from the original info.html design.
